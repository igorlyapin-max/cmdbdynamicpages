# Проверка качества Assistant: 19 октября 2026

## Проверенное Изменение

Контекст Assistant теперь содержит типизированные reference/domain-пути из
доступного каталога, типы, направление, множественность и Help. Контекст ограничен
по глубине, объему и числу проверяемых состояний; усечение обозначается явно.
Бизнес-карточки и ожидаемые ответы не добавляются в этот контекст.

Выбор отображаемой стороны строки отделен от сторон сравнения с родителем.
Подтвержденный binding на именованный результат компилируется детерминированно,
без повторного выбора стадии моделью. Короткие ссылки модели декодируются только
в полях ссылок, не в пользовательских значениях или шаблонах подписей.

Добавлены учет требований с исходными фрагментами текста, проверка противоречий,
ограниченная коррекция и независимый evaluator результатов. Учет требований
не является доказательством понимания произвольного естественного языка.

Для атрибутных связей добавлена необязательная область: оба конца внутри
выбранного контейнера либо вся диаграмма. Она задается в ручном редакторе или
Notes; принадлежность проверяется по фактической структуре, не по именам классов.
Компилятор и runtime не содержат исключений для testtemplate, серверов или VLAN.

Контракты и способы задания Notes описаны в
[assistant-semantic-knowledge.ru.md](assistant-semantic-knowledge.ru.md).

## Границы Вывода

Это адаптивные development-прогоны, не законченный контролируемый A-E эксперимент.
Сохранены все 12 завершенных попыток: 3 успешные, 9 неуспешных, включая одну
ошибку подготовки экспериментального входа. Между попытками менялись prompts и
реализация. Эти доли нельзя объявлять вероятностью успеха модели или процентом
прироста качества. Финальные две попытки прошли без correction retry.

Варианты B/C/D отдельно на production pipeline не измерены. Подготовлены frozen
plan, независимое сравнение снимков, resume и ограничение бюджета для следующего
контролируемого эксперимента. Synthetic fixtures и их оценки отделены от
production результатов; 42 self-tests evaluator проверяют чувствительность
измерителя, а не качество модели.

Существующие Object Flow намеренно сохранены: генерация всех выборок с нуля,
ее точность и перенос на новую предметную область здесь не измерены. Общие
операторы и область контейнера проверены neutral City/Building regression tests;
это не доказательство автоматического discovery произвольных концов связей LLM.
Не измерены стоимость и статистически устойчивое сокращение времени.

Исправлен эффективный default prompt binding; сохраненные пользовательские
prompts и остальные runtime-настройки не перезаписаны. Новая legacy-совместимость
для измененных authoring-контрактов не добавлялась.

находятся локально в `.omk/runs/2026-10-19-assistant-quality/`, не входят в Git
и не должны публиковаться без обезличивания.
